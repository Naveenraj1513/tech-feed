# 📡 tech-intel-feed

A dark, terminal-style web viewer for my daily tech intel briefs.

Paste the HTML/CSS that ChatGPT generates, hit **run / render**, and read it.
Save each day's brief to a dated list and reopen it any time.

🔗 **Live demo:** https://naveenraj1513.github.io/tech-intel-feed/

## ✨ Features

- Renders pasted HTML/CSS in a sandboxed frame
- Dated archive of saved briefs, stored in your browser
- Four dark themes: `cyber`, `matrix`, `dracula`, `amber`
- Fullscreen reading mode
- Works on desktop and mobile
- Single file, no build step, no dependencies

## 🚀 How to use

1. Ask ChatGPT for your daily update as HTML/CSS code
2. Open the live site and click **paste today's brief**
3. Paste the code and click **run / render**
4. Click **save** to keep it in your list

## 🛠️ Tech

HTML, CSS and vanilla JavaScript in a single `index.html`. Hosted on GitHub Pages.

## 🔒 Privacy

Saved briefs are stored in your browser's local storage only. Nothing is sent to any server.
